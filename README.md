# Group_project_CS201
"Іменники і дієслова":
Іменники: Станція (клас), велосипед (клас), звичайний чи електричний (атрибут до велосипеда), номер (атрибут до велосипеда), клієнт (клас), ім'я, баланс (атрибут до клієнта), хвилина (параметр), гроші (атрибут і результат у подальшому), адміністратор (поки що викреслим), мережа (атрибут або метод).
Дієслова: стоять (станція), взяти, покататись, повернути (станція або сервіс оренди), коштує (велосипед), списуються (клієнт), бачити, показати (результат у main). 
"Класи і їхня інформація":
Станція: кількість велосипедів що на ній знаходиться. Вміє: віддати та прийняти велосипед, порахувати кількість велосипедів.
Велосипед: свій номер та свій тип (звичайний чи електричний). Вміє: розрахувати вартість залежно від обраного типу велосипеду та часу поїздки.
Клієнт: ім'я, баланс на рахунку. Вміє: збільшити баланс, списати кошти з балансу, перевірити чи вистачає йому коштів.
