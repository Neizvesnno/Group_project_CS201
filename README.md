"Іменники і дієслова":
Іменники: Станція (клас), велосипед (клас), звичайний чи електричний (атрибут до велосипеда), номер (атрибут до велосипеда), клієнт (клас), ім'я, баланс (атрибут до клієнта), хвилина (параметр), гроші (атрибут і результат у подальшому), адміністратор (поки що викреслим), мережа (атрибут або метод).
Дієслова: стоять (станція), взяти, покататись, повернути (станція або сервіс оренди), коштує (велосипед), списуються (клієнт), бачити, показати (результат у main).
